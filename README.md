# Smart Maintenance System (Smart-MT)

Modern rewrite of the legacy Python (Flask) workshop maintenance application into a high-performance **Golang + Svelte + MySQL** stack. This project is designed for digital machine maintenance management in vocational workshop environments (specifically tailored for Politeknik Negeri Cilacap / PNC standards).

---

## 🚀 Tech Stack
* **Backend:** Golang (RESTful API)
* **Frontend:** Svelte (Vite SPA)
* **Database:** MySQL 8 / MariaDB
